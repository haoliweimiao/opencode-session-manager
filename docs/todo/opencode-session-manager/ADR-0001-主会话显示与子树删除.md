# ADR-0001: 主会话显示与子树删除

opencode 的 `session.parent_id` 指向主会话（子会话 = `task` 工具派生的 subagent，与父同工程同目录），**该列无外键、删除父会话不会自动级联清除子会话**；本工具的目标正是回收磁盘空间，只删主会话会让子会话变成永远不可见的孤儿，DB 反而更臃肿。因此决定：默认只显示主会话（行标「子×N」徽标），勾选主会话即并入其整棵子树（子默认全选，确认弹窗可改并显示孤儿警示），删除顺序子先父后；另设「显示子会话」开关，允许单独勾选删除某个子会话。

**Status**: accepted

**Considered Options**:
- 全平铺展示：199/322（62%）是子会话，噪音过大，否决。
- 树形展开：实测子树深度≤1（子无再子），「子×N」徽标即可完整描述，树形属过早复杂度，否决。
- 删主留子（不合并子树）：制造孤儿、违背回收空间目标，否决。

**Consequences**: 直删模式（单事务 SQL）与 CLI 降级模式都必须枚举子会话一并删除；删除顺序统一子先父后，任一中途退出不产生孤儿。确认弹窗需展示子树完整清单并提示「取消子会话→孤儿」后果。
