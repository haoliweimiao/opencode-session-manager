# Triage 标签

技能以五个规范化的 triage 角色表述。本文件把这些角色映射到本仓库 issue 跟踪器实际使用的标签字符串。

| 技能侧标签 | 本跟踪器标签 | 含义                                        |
| ----------- | ------------ | ------------------------------------------- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue                        |
| `needs-info` | `needs-info`   | 等待报告方补充更多信息                       |
| `ready-for-agent` | `ready-for-agent` | 已完全明确，可供 AFK agent 执行              |
| `ready-for-human` | `ready-for-human` | 需要人工实施                                 |
| `wontfix` | `wontfix`       | 将不予处理                                   |

当技能提到某个角色（例如「加上 AFK 就绪 triage 标签」），使用本表中对应的标签字符串。

如需改用自己的命名，编辑「本跟踪器标签」列即可。
